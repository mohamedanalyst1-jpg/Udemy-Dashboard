#  Udemy Courses Dashboard

An interactive **Tableau** dashboard that analyzes Udemy courses by subject, subscribers, pricing, and level.

![Dashboard Preview](Udemy_Dashboard)

## Overview

The dashboard gives a quick view of the Udemy course catalog and answers questions such as:

- How many courses are there, and what is the **average price** and **average number of reviews**?
- Which **subjects** attract the most subscribers?
- How have **subscriber numbers** changed over the years?
- How many courses are **free** in each subject, and how many have **no subscribers**?

##  Key Metrics

| Metric | Value |
|---|---|
| Count of Courses | 3,677 |
| Average Reviews | 65 |
| Average Price | 66 |

## Visuals Included

- **KPI cards** – course count, average reviews, average price
- **Top Subjects by Subscribers** – Web Development, Business Finance, Graphic Design, Musical Instruments
- **Number of Subscribers by Year**
- **Count of Free Courses by Subject**
- **Non-Subscribed Courses by Subject**
- **Filters** – *Is Paid* and *Level*

## Tools

- Tableau Desktop / Tableau Public

## How to Use

1. Clone or download this repository.
2. Open `Udemy Dashboard.twb` in [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Public](https://public.tableau.com/) (free).
3. Use the filters to explore the data.

> Note: `.twb` files reference the original data source. If Tableau asks for the data file, point it to your local copy of the dataset.
